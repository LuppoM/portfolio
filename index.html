EN PRODUCCIÓN REAL 2 Plantas Industriales Cloud Web App

Sistema Web de Armado de Horarios y Dotación

Aplicación web en la nube que eliminó el circuito caótico de hojas de Excel cruzadas entre 6 supervisores de dos plantas y el equipo de mantenimiento.

El Problema Antes:

Carga manual desordenada, revisiones múltiples entre supervisores y margen de error recurrente al asignar operarios repetidos.

La Solución Actual:

Carga única centralizada en la web. El sistema descarta automáticamente al personal ya asignado en tiempo real.

Puntos Clave del Sistema:

  • Carga única sin revisiones cruzadas
  • Filtrado dinámico de operarios
  • Generación de PDF automático para Planta
  • Consolidado en Excel directo para RRHH

EN PRODUCCIÓN REAL Mantenimiento Industrial Desktop Software (MVC)

Sistema CMMS de Mantenimiento y Órdenes de Trabajo

Software integral desarrollado a medida para centralizar la gestión de mantenimiento preventivo y correctivo de maquinaria industrial en 2 plantas.

El Problema Antes:

Seguimiento de fallas y reparaciones disperso en planillas sueltas, sin historial por máquina ni métricas reales de cumplimiento.

La Solución Actual:

Centralización total en un sistema desktop con base de datos SQL, KPI automático de cierre de OTs y reportes diarios en PDF.

Puntos Clave del Sistema:

  • Control de OTs preventivas y correctivas
  • KPI % de cierre en tiempo real
  • Partes diarios y paradas de fin de semana
  • Notas de pedido y reportes PDF automáticos

DESARROLLADO A MEDIDA Taller de Tornería y Herrería Cloud Web App

Sistema de Presupuestos para Taller de Tornería

Aplicación web desarrollada para un emprendimiento metalúrgico que necesitaba profesionalizar y agilizar sus cotizaciones desde el primer trabajo.

El Problema Antes:

Cálculo manual lento de insumos y horas de trabajo, demoras para responder al cliente y presupuestos informales sin respaldo.

La Solución Actual:

Cotizador web en la nube: se cargan materias primas y mano de obra, calcula el total al instante y genera un PDF formal listo para enviar.

Puntos Clave del Sistema:

  • Carga de materias primas con su costo
  • Suma de mano de obra y total automático
  • PDF del presupuesto listo para el cliente
  • Acceso en la nube desde celular o PC
